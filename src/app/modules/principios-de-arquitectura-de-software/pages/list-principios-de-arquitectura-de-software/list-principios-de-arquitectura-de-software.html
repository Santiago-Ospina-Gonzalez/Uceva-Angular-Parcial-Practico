Principios de una buena arquitectura

Los principios de una buena arquitectura de software son guias que permiten crear sistemas organizados y fáciles de entender. Estos principios como la modularidad,cohesion,acomplamiento y la separación de responsabilidades,ayudan a reducir la complejidad

Modularidad: Consiste en dividir el sistema en partes mas pequeñas con funciones claras y especificas dentro del sistema

Beneficios

Facilita el trabajo en equipo

Reduce la complejidad

Permite reemplazar o mejorar módulos sin afectar todo el sistema

Cohesion:

Indica que tan relacionadas están las tareas dentro del modulomse busca una alta cohesion,cada modulo cumple una sola función

Beneficios:

Facilita la comprensión del código

Hace más simple el mantenimiento

Cada módulo tiene un propósito único y claro

Acompalmiento:

El acoplamiento mide la dependencia entre modulos,Con bajo acoplamiento,los modulos funcionan de forma independiente

Beneficios:

Permite modificar o reemplazar módulos sin afectar a otros

Aumenta la flexibilidad del sistema

Facilidad de evolución del sistema

Separación de responsabilidades:

Consiste en dividir un sistema según distintos tipos de responsabilidades

Beneficios:

Reduce errores al evitar que un cambio en una parte afecte otra innecesariamente.

Facilita la organización en capas o componentes.

Mejora la legibilidad y escalabilidad del sistema.
